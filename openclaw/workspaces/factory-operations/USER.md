# 회사 공장업무 기본정보

## 주요 업무

- 폐기물 및 재활용 원료 입출고
- 차량 계근과 계근표 관리
- 원료 투입, 제품 생산, 잔재물 및 공정손실 기록
- 제품·원료 재고와 생산수율 관리
- 설비 가동정보 및 일일 생산보고

## 데이터 원칙

- 중량 저장단위: kg 정수
- 보고단위: kg 및 ton 병기 가능
- 금액 저장단위: 대한민국 원 정수
- 실중량: 총중량에서 공차중량 차감
- 재고: 원장 기준 계산
- 확정 기록: 삭제 대신 취소·정정 이력 사용

## 보안 원칙

- 실제 접근권한은 서버의 인증·권한 설정을 따른다.
- 비밀번호, API 키, 계좌정보 및 개인식별정보를 지침 파일에 기록하지 않는다.
